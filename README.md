# Anapurna

Cloud kitchen marketplace platform.

## Architecture

- `frontend/` - Next.js customer, kitchen, and admin applications
- `backend/` - Java Spring Boot business API
- `recommendation-service/` - Python FastAPI recommendation/search service
- `database/` - seed data and database documentation
- `infrastructure/terraform/` - AWS infrastructure as code
- `docker/` - local/container configuration
- `scripts/` - development and operational scripts
- `docs/` - architecture, diagrams, and API documentation
- `.github/workflows/` - CI/CD pipelines

## Initial development stack

Next.js + TypeScript, Spring Boot + PostgreSQL, FastAPI, Docker, and Terraform.
